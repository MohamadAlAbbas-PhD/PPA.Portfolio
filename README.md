# Mohamad Al-Abbas — Portfolio Website

This repository powers my personal portfolio website, hosted with **GitHub Pages** and built using **Quarto**.  
The site is a curated home for my **projects**, **technical write-ups**, and an **About** page summarizing my background and research interests.

## What you’ll find on the site
- **About / Summary:** background, research focus, and technical skillset
- **Selected projects:** reproducible analyses, technical appendices, and write-ups
- **Links:** CV, publications, GitHub, LinkedIn, and contact info (as applicable)

## Tech stack
- **Quarto** for site generation
- **GitHub Pages** for hosting
